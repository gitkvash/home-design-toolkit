# სახლის დიზაინის ხელსაწყოები (Home Design Toolkit)

**დაგეგმე ბინის ან სახლის რემონტი AI ასისტენტთან ერთად და შეცდომები იპოვე მანამდე, სანამ ხელოსანი წავა.**

11 უნარი (skills), 4 აგენტი, ბრძანება `/home-design:start` და 4 ტესტირებული ხელსაწყო Claude Code-ისთვის (ან
ნებისმიერი აგენტისთვის, რომელიც Markdown ინსტრუქციებს კითხულობს). ყველაფერი რეალური პროექტიდანაა: 69 მ² ბინა,
შიშველი კარკასიდან ნაყიდ მასალებამდე.

სრულიად უფასო და ღია კოდი (MIT). ანგარიში, API გასაღები და ინსტალაცია არ სჭირდება, მხოლოდ Node 18+.

მეთოდი ნებისმიერ ქვეყანაში მუშაობს: **ჯერ გაზომე, გადაწყვეტილებები ჩაწერე, გეომეტრია შეამოწმე, პროდუქტები
შეადარე ფასით მ²-ზე და ყიდვის შემდეგ კატეგორია დახურე.**

## რა არის შიგნით

- **უნარები**: `home-design-guide` (საიდან დავიწყოთ, სამუშაოს რიგი), `home-survey` (გეგმის სკრინშოტიდან, ფოტოებიდან
  და რულეტით გაზომვიდან სანდო გეგმა), `layout-clearances` (კარების გაშლა, გასასვლელები, დაშორებები),
  `interior-schemes` (შესადარებელი ვარიანტები + ერთი მარტივი), `kitchen-planning` (ტექნიკა, როზეტები, წრედები, გაზი,
  ფილის ჭრა, დურგლის სია), `bathroom-planning`, `lighting-planning` (ლუქსი, ზონები, ჭერის ღრეჩო),
  `finishes-and-quantities` (იატაკი, ფილა, შპალერი რაპორტით და მარაგით, საღებავი, რადიატორი), `product-research`
  (მაღაზიების შედარება ფასით მ²-ზე), `renovation-decisions` (გადაწყვეტილებების ჟურნალი, ბიუჯეტი, სამუშაოთა რიგი),
  `build-3d-room-model`.
- **აგენტები**: `interior-designer`, `layout-auditor` (უშვებს აუდიტს, ხსნის ხარვეზს, გვთავაზობს უმცირეს გასწორებას),
  `product-scout`, `renovation-planner`.
- **ბრძანება**: `/home-design:start` — გასაუბრება და პროექტის მომზადება.
- **ხელსაწყოები**: `clash-audit` (კედელში გასული ავეჯი, გადაფარვები, კარის გაშლა, ვიწრო გასასვლელები; გეგმას ჯერ
  ამოწმებს `plan.schema.json`-ით, არასწორი ან სანტიმეტრებში ჩაწერილი გეგმა კოდით 3 სრულდება), `quantities`
  (ფართობი, ფილა, შპალერის რულონები, საღებავი, რადიატორის ვატები, წრედის დატვირთვა, ლუქსი), `room-viewer`
  (ერთფაილიანი three.js 3D ვიუერი, კარები იღება), `product-research` (ფასების ნორმალიზაცია, დუბლიკატები, სკრეპერის
  შაბლონი).
- **მაგალითი**: გამოგონილი ბინა (`examples/example-flat/`) და გადაწყვეტილებების ჟურნალის ნიმუში.
- **გაკვეთილები**: `docs/lessons-learned.md`.

## დაყენება Claude Code-ში

```
/plugin marketplace add gitkvash/home-design-toolkit
/plugin install home-design@home-design-toolkit
```

შემდეგ ცარიელ საქაღალდეში გაუშვით `/home-design:start`. ტესტები: `npm test`.
