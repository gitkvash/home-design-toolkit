# სახლის დიზაინის ხელსაწყოები (Home Design Toolkit)

უნარები (skills), აგენტი და ხელსაწყო ბინის დაგეგმარებისა და რემონტისთვის AI ასისტენტთან ერთად. ყველაფერი
რეალური პროექტიდანაა: 69 მ² ბინა, შიშველი კარკასიდან ნაყიდ მასალებამდე.

მეთოდი ნებისმიერ ქვეყანაში მუშაობს: **ჯერ გაზომე, გადაწყვეტილებები ჩაწერე, გეომეტრია შეამოწმე, პროდუქტები
შეადარე ფასით მ²-ზე და ყიდვის შემდეგ კატეგორია დახურე.**

## უფასოდ ამ რეპოზიტორიაში

- **უნარები**: `home-design-guide` (საიდან დავიწყოთ, სამუშაოს რიგი), `home-survey` (გეგმის სკრინშოტიდან, ფოტოებიდან
  და რულეტით გაზომვიდან სანდო გეგმა), `layout-clearances` (კარების გაშლა, გასასვლელები, დაშორებები).
- **აგენტი**: `layout-auditor` — უშვებს აუდიტს, ხსნის თითოეულ ხარვეზს და გვთავაზობს უმცირეს გასწორებას.
- **ხელსაწყო**: `tools/clash-audit` — პოულობს კედელში გასულ ავეჯს, გადაფარვებს, კარის გაშლის დაბრკოლებებს და ვიწრო გასასვლელებს. გეგმას ჯერ ამოწმებს `tools/clash-audit/plan.schema.json`-ით: არასწორი გეგმა (ან სანტიმეტრებში ჩაწერილი მეტრების ნაცვლად) კოდით 3 სრულდება და ჩამოთვლის, რა არის არასწორი. ტესტები: `npm test`.
- **მაგალითი**: გამოგონილი ბინა (`examples/example-flat/plan.json`).
- **გაკვეთილები**: `docs/lessons-learned.md`.

## Pro ვერსია (ფასიანი)

კიდევ 8 უნარი და 3 აგენტი: სამზარეულო (ტექნიკა, როზეტები, წრედები, გაზი, ფილის ჭრა, დურგლის სია), სააბაზანო,
განათება, მასალები და რაოდენობა კალკულატორით (იატაკი, ფილა, შპალერი, საღებავი, რადიატორი), პროდუქტების ფასების
შედარება, დიზაინის ვარიანტები, გადაწყვეტილებების ჟურნალი და 3D ვიუერი. დაინტერესების შემთხვევაში გახსენით issue.
